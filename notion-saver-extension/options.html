Save to Notion

Saves pages straight into a Notion database — works from anywhere, no app open.

First time? Setup in 3 steps
  1. Create an integration at notion.so/my-integrations and copy its Internal Integration Secret (starts with ntn_).
  2. Open your database → top-right ••• → Connections → add your integration.
  3. Copy the database URL (or its 32-char ID) and paste it below.

Your database needs these columns: Name (Title), URL, Tags (Multi-select), Note (Text), Saved (Date), Concept and Subconcept (Select). Concept inputs follow the table’s options.

Integration token The secret from your Notion integration.
Databases Add one or more. You'll pick which to save to from the popup. Paste each database's URL (or 32-char ID).
Default tags Added to every saved link (optional).
